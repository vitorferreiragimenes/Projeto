DEMONSTRAÇÃO DE BOAS PRÁTICAS

Formulário inclusivo por design.

Este formulário exemplifica as diretrizes WCAG para formulários acessíveis: labels sempre visíveis, feedback claro, sem bloqueio de funções do navegador.

  • ✓ Labels sempre visíveis acima do campo — nunca como placeholder substituído
  • ✓ Indicação clara de campos obrigatórios com label e atributo aria-required
  • ✓ Feedback de erro com role="alert" e descrição textual do problema
  • ✓ Feedback de sucesso por campo com role="status"
  • ✓ Autocomplete nativo do navegador totalmente habilitado
  • ✓ Copiar, colar e seleção de texto liberados sem restrições
  • ✓ Foco visível em todos os campos com contorno de 3px
  • ✓ Placeholder é complementar, não substitui o label

Nota para usuários: Copiar e colar (Ctrl+C / Ctrl+V) é totalmente permitido em todos os campos. O preenchimento automático do navegador também é suportado — use como preferir.
